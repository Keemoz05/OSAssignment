to run this :

1. do:

   - gcc launcher.c -o launcher
   - gcc server.c -o server
   - gcc player.c -0 player

2. run 

    ./launcher

3. what does it do for each file

    player.c => logic of the game or the program run by each process
    server.c => logging for each players in a game
    launcher.c => run both player and server program
